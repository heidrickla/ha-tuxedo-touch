# Honeywell Tuxedo Touch (local API)

A Home Assistant custom integration for the Honeywell Tuxedo Touch WIFI security/home
automation controller (TUXWIFIS/TUXWIFIW).

Full documentation - requirements, installation, HTTPS notes, and known limitations -
lives in the [repository README](../../README.md). The reverse-engineering writeup behind
the implementation is in [docs/tuxedo_touch_api_notes.md](../../docs/tuxedo_touch_api_notes.md).
